# ロシア文字練習帳

ロシア語のアルファベット（キリル文字）33 文字を、一覧・クイズ・読み上げ・発音チェック・解説で練習できる静的 Web アプリです。
HTML / CSS / JavaScript のみで動作します。歌「カチューシャ」の単語の日本語クイズ付き。

# DEMO

https://kubo-4ka.github.io/russian-azbuka/

## 起動

```bash
node tools/serve.js
```

http://localhost:26834/ を開きます。スマホから発音チェック（マイク）やオフライン動作を試すときは HTTPS が必要です（`node tools/make-cert.js` → `node tools/serve.js --https`）。

## 機能

画面下のメニューで 6 つの画面を切り替えます。

- **クイズ**（5／10／20／33 問／全部）
  - 文字：文字を読む／音から文字／イタリック・筆記体（形の変わる小文字）
  - 単語：単語を読む／読みから単語／聞き取り（要ロシア語音声）／書き取り（画面キーボード：アルファベット順か ЙЦУКЕН 配列。PC のキーボードでも入力可）
  - 文法・発音：アクセントの位置／名詞の性
  - カチューシャ：歌の単語 → 日本語／日本語 → 歌の単語／歌詞の穴埋め（歌詞を入力したときだけ）
  - 間違えた文字・単語を多めに出題、結果から「間違えた問題だけ」再挑戦
- **文字**：33 文字をグループ別（形も音も同じ／ニセモノ注意／ギリシャ文字に似ている／見慣れない形／記号）に表示。ふつう・イタリック・筆記体の切り替え。タップで名前・発音のコツ・例の単語
- **解説**：キリル文字のなりたち、硬母音と軟母音、アクセントと弱化、無声化と同化、例外的な読み、書体、文の基本（冠詞・be 動詞なし）、名詞の性、6 つの格、動詞の変化、体（アスペクト）、名前・父称・愛称、ты と вы、数字。ロシア語の例はタップで読み上げ
- **カチューシャ**：歌の紹介、歌に出てくる単語（辞書形）の一覧、歌詞を入力して練習（単語・行の読み上げ、ラテン文字の読み、発音チェック、穴埋めクイズ）
- **発音**：お手本の読み上げ（ふつう／ゆっくり）と、音声認識による発音チェック（一致度と、聞き取れなかった文字の表示）。自由入力の文も読み上げ・チェックできます
- **説明**：使い方、読み上げ音声の入れ方、出典
- ホーム画面に追加してアプリとして使える（PWA）、ライト／ダークテーマ

## 歌詞の扱い

「カチューシャ」の歌詞（作詞：ミハイル・イサコフスキー、1973 年没）は日本でも著作権の保護期間中のため、**アプリには収録していません**。
収録しているのは歌に出てくる単語（辞書形）と、その意味・解説だけです。
歌詞の行を使う機能（穴埋め・行ごとの読み上げ・発音チェック）は、利用者が自分で入力した歌詞をブラウザの localStorage に保存して使います（外部送信なし）。

## ファイル構成

| ファイル                                                    | 内容                                                                     |
| ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| `index.html`                                                | 画面                                                                     |
| `style.css`                                                 | デザイン（色は `:root` のトークンで管理）                                |
| `app.js`                                                    | アプリ本体（クイズ・読み上げ・音声認識など）                             |
| `data.js`                                                   | 文字・単語のデータ。ここを編集すれば単語を追加できます                   |
| `guide.js`                                                  | 「解説」タブの本文                                                       |
| `manifest.webmanifest` / `sw.js` / `icons/` / `favicon.svg` | アプリとしてインストールするための設定・オフライン用キャッシュ・アイコン |
| `tools/serve.js`                                            | ローカル確認用サーバ（ポート 26834、`--https` 対応）                     |
| `tools/make-cert.js`                                        | ローカル HTTPS 用の自己署名証明書を作る（要 openssl）                    |
| `tools/make-icons.ps1`                                      | アイコン PNG を作り直す（Windows PowerShell）                            |

### data.js の書き方

```js
{ w: 'рестора+н', kana: 'リスタラーン', ja: 'レストラン', cat: 'loan', g: 'm', note: '…' }
```

- `w`：単語。強く読む母音の**直後に `+`** を書くと、画面ではアクセント記号（́）付きで表示されます。読み上げ・答え合わせでは取り除かれます
- `kana`：発音のめやす（母音の弱化・無声化を反映した読み）
- `cat`：`loan`（外来語）／`greet`（あいさつ）／`culture`（ロシアらしい言葉）／`basic`（基本の言葉）／`song`（カチューシャ）
- `g`：名詞の性（`m`／`f`／`n`）。付けると「名詞の性」クイズに出ます。`gnote` で覚え方を添えられます

### 更新するとき

ファイルを変更したら、`sw.js` の `VERSION`（例：`az-v1` → `az-v2`）を上げてください。

## 読み上げ・発音チェックについて

- 読み上げは Web Speech API（端末のロシア語音声）を使います。ロシア語の声がない端末では読み上げと「聞き取り」クイズが使えません
- 発音チェックは SpeechRecognition（Chrome・Edge・Safari）で、`https` か `localhost` でのみ動作します。多くのブラウザでは音声が提供元のサーバーへ送られて認識されます
