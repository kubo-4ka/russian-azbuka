カチューシャ

1938 年に作られたソビエトの歌謡曲です。岸辺で恋人を想う娘カチューシャの歌で、遠い国境で働く兵士に歌声を届けたいという内容が歌われます。第二次世界大戦中に広く歌われ、日本でも戦後に日本語の訳詞で親しまれました。

題名の Катю́ша は、女性の名前 Екатери́на（エカテリーナ）の愛称です（「解説」の「名前・父称・愛称」も参照）。大戦中のソ連軍の多連装ロケット砲も、この歌にちなんで「カチューシャ」と呼ばれました。

歌に出てくる単語

歌詞で練習する

歌詞はアプリに収録していません

「カチューシャ」の歌詞（作詞：イサコフスキー、1973 年没）は日本でもまだ著作権の保護期間中のため、本アプリには収録していません。お手持ちの歌集や CD の歌詞カードなどを見ながら、下の欄にロシア語の歌詞を入力（貼り付け）すると、その歌詞で読み上げ・発音チェック・穴埋めクイズができます。

入力した歌詞は、お使いのブラウザの中だけに保存されます。外部へ送信したり、他の人と共有したりはしません。

ほかの歌や文章でも使えます。アクセントの位置がわかる場合は、強く読む母音の後ろに + を書くとアクセント記号付きで表示します（例：Катю+ша）。

単語をタップすると読み上げ、行の ♪ で 1 行を読み上げ、🎤 でその行の発音チェックへ移ります。ラテン文字の読みは機械的に転写したもので、アクセントによる母音の弱化などは反映されません。

自由に入力して読み上げ

読み上げの設定

発音チェックのしくみ
  • 「話してみる」を押してから言葉を読むと、ブラウザの音声認識（ロシア語）が聞き取った文字を表示し、お手本とどれくらい一致したかを示します。
  • 音声認識は「ネイティブにどう聞こえたか」のめやすです。発音の細かな採点ではありません。1 文字だけ・短い単語は認識されにくいので、単語や短い文で試すのがおすすめです。
  • Chrome・Edge・Safari で使えます（Firefox は非対応）。多くのブラウザでは、録音した音声が認識のためにブラウザの提供元のサーバーへ送られます。

このアプリについて

ロシア語のアルファベット（キリル文字）33 文字を読めるようになることを目指す練習帳です。文字の形と音を覚え、外来語やあいさつを読んで「読めた！」を積み重ね、歌「カチューシャ」の単語や、ご自分で入力した歌詞で練習できます。

練習のしかた

文字
33 文字の一覧です。「ニセモノ注意」（В・Н・Р・С・У・Х など）のように、覚えやすいグループに分けています。書体をイタリック・筆記体に切り替えると、形の変わる文字を確認できます。
クイズ
文字→音、音→文字、イタリック・筆記体、単語を読む、聞き取り、書き取り、名詞の性、カチューシャの単語、歌詞の穴埋めがあります。間違えた文字・単語ほど多く出題されます。
解説
アクセントと母音の弱化、無声化、例外的な読み方、名詞の性・格、動詞の変化と体、名前と愛称など、ロシア語ならではの事柄をまとめています。
カチューシャ
歌に出てくる単語の一覧と、歌詞を入力して練習する機能です。
発音
お手本の読み上げと、マイクを使った発音チェックです。

カタカナの読みについて

単語に付けたカタカナは、アクセントによる母音の弱化（о → ア など）や無声化を反映した「実際の発音に近いめやす」です。つづりを 1 文字ずつ置き換えた読みとは違うことがあります。カタカナでは表せない音（ы、柔らかい子音、巻き舌の р など）もあるので、♪ のお手本と合わせて確認してください。

読み上げについて

読み上げにはお使いの端末・ブラウザに入っているロシア語の音声を使います。ロシア語の声が見つからない場合は読み上げできません。

  • Windows：設定 → 時刻と言語 → 言語と地域 → 言語を追加 で「ロシア語」を追加し、音声（音声合成）をインストール。Edge なら追加しなくても「Microsoft Svetlana / Dmitry (Online)」が使えることがあります
  • iPhone：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → ロシア語
  • Android：Google の音声サービスの設定で、ロシア語の音声データをインストール

アプリとして使う

ホーム画面に追加すると、アプリのように全画面で使えます。https:// で公開されたページから追加した場合は、一度開いたあとオフラインでも動きます（読み上げの一部の声と発音チェックはネット接続が必要です）。

データの保存

正答率・設定・入力した歌詞は、お使いのブラウザの中だけに保存されます。外部へ送信されることはありません（発音チェックの音声認識を除く）。
